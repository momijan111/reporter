# 母の入院記録（Mother Hospital Log）

入院中の家族の毎日の様子を、スマホから記録しておくためのアプリです。

スマホのブラウザで開いて「ホーム画面に追加」すると、ふつうのアプリのように使えます（PWA）。
App Store や Google Play への登録は不要です。

**公開URL: https://momijan111.github.io/reporter/**

## 記録すること

1日につき、次の3つだけです。

### 1. 起きていたか（3つの時間帯 × 3段階）

記録する時間帯は **昨日の夜／昼間／面会時間** の3つ。
それぞれを次の3段階で選びます（時刻は入力しません）。

| 段階 | 色 |
| --- | --- |
| よく起きている | 緑 |
| 少し起きてる | オレンジ |
| 寝てる | 赤 |

### 2. 使っている薬

一度登録しておけば、以降は**選ぶだけ**で記録できます。
薬の一覧は家族全員で共有されます。

- 設定画面の「薬の登録」から追加・修正
- 記録の画面でも「＋ 薬を登録」でその場で追加できます
- 使わなくなった薬は「使用をやめる」で一覧から隠せます
  （過去の記録では名前が残ります）

### 3. メモ

様子、話したこと、先生や看護師さんから聞いたこと、気づいたことなど、
自由に書き残せます。

### 4. 写真・動画

「写真を撮る」「動画を撮る」を押すと、**その場でカメラが立ち上がります**。
撮ったものはそのまま記録に残ります（写真は保存前に自動で小さくします）。

## トップ画面はカレンダー

1か月ぶんがマス目で並びます。1日のマスは **左＝昨日の夜／中＝昼間／右＝面会時間**
の3本の色だけで表すので、月全体の調子の移り変わりがひと目で分かります。

- 左右の矢印（横スワイプでも可）で月を移動
- 記録がある日をタップ → その日の記録を開く
- 記録がない日をタップ → その日の記録を新しく作る
- 今日のマスには枠がつきます
- 写真・動画がある日は右上に小さな点がつきます

## そのほかの機能

- **文章としてコピー**：1日ぶんの記録をテキストにして、LINE などに貼り付け
- **言葉でさがす**：記録が4件以上になると、カレンダーの下の検索欄からメモの中身を探せます
- **バックアップ**：全記録（写真・動画つきも可）をファイルに書き出し／読み込み
- **オフライン対応**：一度開けば、電波がない病院内でも使えます

## 家族と共有する

設定画面の「家族と共有」から、家族で決めたメールアドレスと合い言葉でログインすると、
**家族全員が同じ記録を見られます**。

- 共有されるもの：日付・3段階・**薬**・メモ・**写真**・薬の登録一覧
- 共有されないもの：**動画**（容量が大きいため、撮った端末の中だけに残ります）
- **同期は自動です。**家族の誰かが書くとすぐ（1〜2秒で）ほかの端末に届きます
- 電波がないところでも記録でき、つながったときに自動で家族と合わせます
- 同じ日の記録を2人が同時に直した場合は、**あとに保存したほう**が残ります

設定の手順（1回だけ・10〜15分）は **[docs/sharing-setup.md](docs/sharing-setup.md)** にあります。

## 記録はどこに保存される？

いつでも**この端末の中**（ブラウザの IndexedDB）に保存され、
家族と共有している場合は、そこに加えてクラウド（Supabase）にも保存されます。

- 共有していないときは、記録はインターネットに送られません
- ブラウザのデータを消したり端末を変えたりすると、その端末の記録は消えます
  （共有していれば、ログインし直すと戻ってきます。動画は戻りません）
- 動画は容量が大きいので、撮りすぎると端末の空き容量が足りなくなることがあります

→ ときどき「設定」画面から **バックアップを書き出して** おくと安心です。
新しい端末では、同じ画面から読み込めば復元できます。

## スマホで使う準備

1. スマホのブラウザで https://momijan111.github.io/reporter/ を開く
2. ホーム画面に追加する
   - **iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」
   - **Android（Chrome）**：右上のメニュー → 「ホーム画面に追加」／「アプリをインストール」

## 開発のはじめかた

必要なもの：[Node.js](https://nodejs.org/)（バージョン 20 以上）

```bash
npm install      # 最初の1回だけ
npm run dev      # 開発用サーバーを起動（表示された URL をブラウザで開く）
```

そのほかのコマンド：

```bash
npm run build    # 公開用のファイルを dist/ に作る
npm run preview  # dist/ の中身を実際に開いて確認する
npm run lint     # 書き方のチェック
```

アイコン画像を作り直したいとき：

```bash
node scripts/generate-icons.mjs
```

## 公開のしかた

`.github/workflows/deploy.yml` により、**既定のブランチに push すると自動で
ビルドされて GitHub Pages に公開されます**。

> **注意**：GitHub Pages は「既定のブランチからの公開」しか許可しません。
> 既定のブランチが `main` でない場合、`main` に push しても公開されません。
> GitHub の Settings → General → Default branch で `main` を既定にしてください。

## 共有のしくみ

端末の中（IndexedDB）を本体とし、クラウドとは次の2つをするだけです。

1. クラウドにあって、こちらより新しいものを取り込む
2. こちらにあって、クラウドより新しいものを送る

合わせるタイミングは次のとおりで、ふだん手で操作する必要はありません。

- **家族の誰かが記録を変えたとき**（Supabase Realtime ですぐ知らせが届く）
- アプリを開いたとき・別のアプリから戻ったとき
- 記録を保存／削除したとき
- 電波が戻ったとき
- 開いている間、5分ごとの確認（念のため）
- 設定画面の「今すぐ合わせる」を押したとき（ふだんは不要）

消した記録は、家族にも「消した」と伝える必要があるので、
すぐ消さずに `deleted` の印をつけて残しています。

## 注意

このアプリは家族が様子を書き残すためのものです。
医療上の判断は、必ず主治医や病院のスタッフにご相談ください。
