# 母の入院記録（Mother Hospital Log）

入院中の家族の毎日の様子を、スマホから記録しておくためのアプリです。

スマホのブラウザで開いて「ホーム画面に追加」すると、ふつうのアプリのように使えます（PWA）。
App Store や Google Play への登録は不要です。

## できること

- **日ごとの記録**：日付・面会時間・全体の調子（5段階）
- **体調・バイタル**：体温／血圧／脈拍／SpO2／食事量（主食・副食）／水分／睡眠／排泄／メモ
- **意識・会話の様子**：受け答えのレベル／こちらを認識できたか／表情／話した言葉／メモ
- **リハビリ・できたこと**：受けたリハビリ（PT・OT・ST・看護）／内容／できたこと／メモ
- **医師・看護師から聞いた話**：話した人／内容／薬の変更／次回の予定
- **写真**：保存前に自動で縮小してから端末内に保存
- **調子のグラフ**：「全体の調子」の移り変わりを折れ線で表示
- **言葉でさがす**：記録の中身をキーワードで絞り込み
- **文章としてコピー**：1日ぶんの記録をテキストにして、LINE などに貼り付け
- **バックアップ**：全記録（写真つきも可）を JSON ファイルに書き出し／読み込み
- **オフライン対応**：一度開けば、電波がない病院内でも使えます

## 記録はどこに保存される？

**この端末の中だけ**です（ブラウザの IndexedDB）。インターネットには送られません。

そのため、次の点に注意してください。

- ブラウザのデータを消すと、記録も消えます
- 端末を変えると、記録は引き継がれません
- ほかの家族のスマホからは見られません

→ ときどき「設定」画面から **バックアップを書き出して** おくと安心です。
新しい端末では、同じ画面から読み込めば復元できます。

## スマホで使う準備

1. 下の「公開のしかた」でアプリをネット上に置く
2. スマホのブラウザでその URL を開く
3. ホーム画面に追加する
   - **iPhone（Safari）**：共有ボタン → 「ホーム画面に追加」
   - **Android（Chrome）**：右上のメニュー → 「ホーム画面に追加」／「アプリをインストール」

## 開発のはじめかた

必要なもの：[Node.js](https://nodejs.org/)（バージョン 20 以上）

```bash
npm install      # 最初の1回だけ
npm run dev      # 開発用サーバーを起動（表示された URL をブラウザで開く）
```

そのほかのコマンド：

```bash
npm run build    # 公開用のファイルを dist/ に作る
npm run preview  # dist/ の中身を実際に開いて確認する
npm run lint     # 書き方のチェック
```

アイコン画像を作り直したいとき：

```bash
node scripts/generate-icons.mjs
```

## 公開のしかた

### GitHub Pages（このリポジトリに設定済み）

`.github/workflows/deploy.yml` を入れてあります。

1. GitHub のリポジトリ画面で **Settings → Pages** を開く
2. **Source** を **GitHub Actions** にする
3. `main` ブランチに push する（自動でビルドされて公開されます）

公開先の URL は `https://<ユーザー名>.github.io/<リポジトリ名>/` です。

### Vercel / Netlify を使う場合

リポジトリを連携して、次の設定にします。

- ビルドコマンド：`npm run build`
- 公開ディレクトリ：`dist`

```

  sw.js                  オフラインで使うための仕組み
  icon-*.png             アプリのアイコン
scripts/
  generate-icons.mjs     アイコン画像を作るスクリプト
src/
  App.tsx                画面の切り替えのまとめ役
  types.ts               記録のデータの形
  data/labels.ts         選択肢と日本語ラベル
  lib/
    db.ts                IndexedDB のかんたんな道具
    storage.ts           保存先（あとで差し替えられるようにしてある）
    record.ts            日付の整形、文章化などの便利関数
    backup.ts            バックアップの書き出し・読み込み
    image.ts             写真の縮小
  components/            画面の部品
```

## あとでクラウド保存（家族と共有）を足すには

保存まわりは `src/lib/storage.ts` の `RecordStore` という形に集めてあります。
画面側はこの形しか使っていないので、**同じ形の別の実装を作って差し替えるだけ**で移行できます。

```ts
// src/lib/storage.ts
export const store: RecordStore = localStore  // ← ここを差し替える
```

たとえば Supabase を使う場合は、`listRecords` / `getRecord` / `saveRecord` /
`deleteRecord` / `getPhoto` / `savePhoto` / `deletePhoto` の7つを
Supabase 版で書いた `supabaseStore` を用意して、上の行を差し替えます。

## 注意

このアプリは家族が様子を書き残すためのものです。
医療上の判断は、必ず主治医や病院のスタッフにご相談ください。
